# お団子キャッチ（test）

約10秒で落ちてくるお団子を集める、短時間のブラウザミニゲームです。画面の下のお皿を左右に動かし、お団子を受け止めながらケーキを避けて得点を競います。

## 遊び方

1. 名前を入力し、「いざ、開始」で始めます。
2. 画面を左右にスワイプしてお皿を動かします。
3. お団子🍡は1点加算、ケーキ🍰は3点減点。全てのお団子・ケーキが落ち終わると終了し、結果を表示します。
4. 「もう一度挑む」で再挑戦できます。結果の共有用文面も用意しています。

## 記録と起動

ゲーム本体は [index.html](index.html) にあります。リポジトリをダウンロードまたはcloneして、手元の `index.html` をブラウザで開いてください。GitHub上のファイルリンクはソース表示です。

結果画面にはTOP10ランキングがあり、名前と得点を外部のランキングへ送信する実装があります。通信成功や公開先の稼働は今回のREADME更新では未検証です。
